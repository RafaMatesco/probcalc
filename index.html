Formulário de Referência

1. Distribuição Binomial

Variável aleatória discreta com n provas independentes e probabilidade de sucesso p constante.

P(X = k) = [n! / (k! · (n - k)!)] · pᵏ · qⁿ⁻ᵏ
Onde: q = 1 - p  |  E(X) = n · p  |  Var(X) = n · p · q

2. Distribuição Geométrica

Tentativas independentes até a obtenção do 1º sucesso.

P(X = n) = qⁿ⁻¹ · p
Onde: q = 1 - p  |  Acumulada: P(X ≤ n) = 1 - qⁿ

3. Distribuição de Poisson

Contagem de eventos raros em intervalos de tempo ou espaço contínuo.

P(X = x) = (e⁻ᵝ · μˣ) / x!
Onde: μ = λ · t  |  e ≈ 2,71828  |  E(X) = μ  |  Var(X) = μ

4. Distribuição Normal (Gaussiana)

Padronização para tabela de Faixa Central P(0 ≤ Z ≤ z):

z = (X - μ) / σ
  • P(X < X₁) com z < 0: Área = 0,5 - Tabela(|z|)
  • P(X < X₁) com z > 0: Área = 0,5 + Tabela(|z|)
  • P(X > X₁) com z > 0: Área = 0,5 - Tabela(|z|)
  • P(X > X₁) com z < 0: Área = 0,5 + Tabela(|z|)
  • P(X₁ < X < X₂) lados opostos: Tabela(|z₁|) + Tabela(|z₂|)
  • P(X₁ < X < X₂) mesmo lado: |Tabela(|z₂|) - Tabela(|z₁|)|
